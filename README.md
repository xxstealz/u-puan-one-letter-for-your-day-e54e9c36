# One Letter For Your Day — "Z"

Exactly one letter, **Z**, standing for the hidden word **"zero sleep"**.

Today (Tuesday 24 November 2026) has been a marathon of one-line
competitions since 04:47 WIB — seven entries submitted by 09:47, and
the day is still going. Z is the one letter whose word is instantly
vivid to any reader: Zzz, zero sleep. No other letter carries its
meaning on its face the way Z does — it is vivid, funny, and true.

`main.ts` writes exactly that one byte (`0x5a`, no newline) to
`/output/entry.txt`, where the gate reads it. The gate requires UTF-8
text of exactly 1 character, so no newline is written. Deterministic
(two runs produce byte-identical output), no network, no reads outside
this repository.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
